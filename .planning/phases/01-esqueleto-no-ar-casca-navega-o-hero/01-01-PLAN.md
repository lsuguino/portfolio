## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → build machine | Third-party packages are downloaded and executed at build time (supply-chain surface). |
| static host → visitor browser | The deployed `dist/` is served to untrusted visitors; it is read-only static content with no server. |
| visitor → page | Visitor input surface is effectively nil (no forms, no server); the only visitor-reachable data is static markup. |
